= Usage with Secryst

Secryst is the neural layer of Interscript: distilled, byte-level
models for conversions that have no authority map — diacritization,
grapheme-to-phoneme, homograph disambiguation. The models ship as
checksummed IMF v1 artifacts resolved from the
https://github.com/interscript/interscript-ml[interscript-ml] index;
nothing is bundled in the library.

== Install

[source,ruby]
----
gem install secryst      # Ruby
----

[source,sh]
----
pip install secryst      # Python
npm install secryst      # TypeScript / JavaScript
----

== Loading a model

Models resolve by id against the public index, download once into a
content-addressed cache, and verify every member checksum on load:

[source,ruby]
----
require "secryst"

model = Secryst::Model.load("tha-g2p-small-1.0")
model.translate("สวัสดี")
# => "sa˨˩.wat̚˨˩.diː˧"
----

== Catalog

The catalogue of released models — with the measured metric next to
each teacher's, per the published protocol — lives at
https://interscript.org/ml[/ml] and in the
https://github.com/interscript/interscript-ml/blob/main/docs/RESULTS.md[results log].

== Deployment overrides

Both overrides are read at call time in all three runtimes:

* `SECRYST_INDEX` — a models.yaml URL or path (mirror or pin)
* `SECRYST_CACHE` — cache directory (default `~/.cache/secryst`)

== Usage inside maps

Neural conversion composes with deterministic stages:

[source,ruby]
----
stage {
  # ... sub "a", "b" ...
  secryst model: "model-name"
  # ... sub "c", "d" ...
}
----
